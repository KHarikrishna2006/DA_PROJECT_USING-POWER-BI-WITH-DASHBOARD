# DA_PROJECT_USING-POWER-BI-WITH-DASHBOARD
Project Overview
This project involves analyzing survey data of data professionals to gain insights into industry trends, demographics, or skill distributions. The focus was on end-to-end data processing, from raw data extraction to building interactive visualizations.

🛠 Tools & Technologies
Power BI Desktop: Used for data transformation, modeling, and visualization.
Power Query: Utilized for data cleaning, removing unnecessary columns, and formatting types.
Excel/CSV: Source data format.
🔍 Data Transformation (Power Query)
Key steps taken to clean the data included:

Removed irrelevant columns to improve performance and clarity.
Standardized data types for accurate calculations.

📊 Key Insights & Visualizations
